# multiOS iOS Safari WebKit Interoperability & Touch Gestures

Specifications for mobile touch ergonomics and Safari WebKit compatibility layers.

## Touch Interactions

- **Haptic Pull-to-Refresh:** Pull gesture over the incoming gallery initiates lightweight metadata re-validation with native haptic clicks.
- **Drag & Drop Integration:** iOS Safari file drop zone supports multi-selection drag-and-drop from the iOS Files app.
- **Orientation Adaptation:** Responsive layout adapts across compact portrait and wide landscape displays (iPad Split View support).
