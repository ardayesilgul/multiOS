# multiOS Windows 11 Shell JumpList & Notification Protocol

Details on Windows taskbar integration, dynamic JumpList recent destinations, and action button bindings.

## Taskbar & Shell JumpList

- **Recent Files:** Automatically populates the Windows taskbar context menu with the 5 most recently received documents.
- **Quick Actions:** Provides direct one-click JumpList actions for "Pause Clipboard Sync" and "Open Received Folder".
- **Badge Indicators:** Updates native taskbar icon overlays with an unread badge counter when new files arrive while the window is minimized.
